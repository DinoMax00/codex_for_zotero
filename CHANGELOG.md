# Changelog

## 0.6.0 — 2026-11-03

First public release.

- Minimal Zotero sidebar with native Codex sessions, model selection, per-paper history, title editing, and forwarded permission prompts.
- Automatic first-turn PDF references, multi-turn conversations, streaming progress, cancellation, and completion states.
- Sanitized Markdown, native MathML formulas, compact local PDF citations, and contained scrolling.
- Enter to send, Shift + Enter for a newline, and IME-aware input.
- One-click Chinese paper annotations through an authenticated background endpoint.
- Companion skills for native highlights and collection-aware paper imports.
- English documentation, MIT license, offline tests, privacy checks, clean release packaging, SHA-256 checksums, and a GitHub-hosted Zotero update manifest.

Earlier 0.1–0.5 builds were local development versions and are not public releases.
